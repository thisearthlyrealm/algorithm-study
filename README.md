### 🧬 深度学习

**基础架构**
- 全连接神经网络（MLP）
- 激活函数：ReLU · Sigmoid · Tanh · LeakyReLU · GELU
- 损失函数：MSE · CrossEntropy · Hinge · Focal Loss
- 优化器：SGD · Momentum · Adam · AdamW · RMSprop
- 正则化：Dropout · BatchNorm · LayerNorm · L1/L2

**卷积神经网络（CNN）**
- LeNet · AlexNet · VGG · ResNet · DenseNet
- 空洞卷积 · 深度可分离卷积 · 转置卷积
- 目标检测：YOLO · Faster R-CNN · SSD
- 图像分割：U-Net · Mask R-CNN · DeepLab

**循环神经网络（RNN）**
- RNN · LSTM · GRU · 双向 RNN
- 序列到序列（Seq2Seq + Attention）
- 时序预测与文本生成

**Transformer 与注意力机制**
- Self-Attention · Multi-Head Attention · Cross-Attention
- Transformer（Encoder / Decoder）
- Vision Transformer（ViT）· Swin Transformer

**生成模型**
- 变分自编码器（VAE）
- 生成对抗网络（GAN）：DCGAN · WGAN · CycleGAN
- 扩散模型（Diffusion Models）

**图神经网络（GNN）**
- GCN · GAT · GraphSAGE
- 节点分类 · 链接预测 · 图分类
